# 数据处理参数整理说明

本说明根据以下两个流程文档整理：

```text
I:\zhushou\agent\s1数据处理图文流程v2.0.docx
I:\zhushou\agent\数据处理图文流程v3.0.docx
```

当前目标不是执行 GAMMA，而是让网页能生成更合理的 Linux 处理配置草稿。

## 1. 参数分类

### 必须由用户填写

这些参数无法从默认值可靠推断：

```text
task_id
task_root
raw_zip_dir
dem_file
master_date
bn_start1
bn_end1
env_scripts
matlab_func_dir
```

原因：

```text
- 数据路径、DEM 路径、任务目录取决于 Linux 主机实际存放位置。
- master_date 取决于用户选择的主影像。
- burst 起止编号需要根据研究区和预览判断。
- env_scripts 和 matlab_func_dir 取决于 Linux 上 GAMMA、StaMPS、MATLAB 的安装位置。
```

### 需要显式确认但有推荐默认值

这些字段有文档示例或代码默认值，但仍会影响处理路线：

```text
satellite: S1A
polarization: VV
swath: IW1
enable_crop: true
diff_method: initial
shp_method: HTCI
phase_opt_method: evd_sbas_single
point_selection_method: dsc_pds
stamps_mode: sbas
```

它们显示在网页的主表单中，不放进高级折叠区。

### 启用裁剪时必须填写

```text
crop_roff
crop_nr
crop_loff
crop_nl
```

流程文档中裁剪范围需要先用 `rasSLC` 成图并打开预览图判断，不能盲目使用固定默认值。因此代码不再为这些字段提供默认值。

### 高级默认参数

这些字段来自流程文档中的常用值、命令示例或旧代码默认值，默认折叠，但可以展开修改：


## 2. 本次根据文档调整的重点

### 裁剪参数

旧版本里曾经有：

```text
crop_roff: 0
crop_nr: 2000
crop_loff: 0
crop_nl: 3000
```

现在已经取消这些默认值。启用裁剪时，它们必须来自裁剪预览或人工框选。

### 多视参数

流程文档中说明重新地理编码、差分干涉时多视比习惯用 `5:1`，因此：

```text
rlks: 5
azlks: 1
```

### base_calc 时间基线

流程文档 SBAS 示例为：

```text
base_calc RSLC_tab 主影像RSLC_par bperp_fileSBAS itabSBAS 1 1 - 200 - 37 2
```

因此：

```text
bperp_max: 200
delta_t_max: 37
delta_n_max: 2
```

### 阈值

流程文档说明：

```text
SBAS 通常为 0.6
PS 通常为 0.4
```

当前默认处理路线是 `sbas`，所以保留：

```text
fit_threshold: 0.6
psc_da_thresh: 0.6
```

如果用户选择 PS 路线，应考虑改为 `0.4`。
